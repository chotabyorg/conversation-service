# Main Chota Platform — Conversation Service

Standalone communication lifecycle foundation for Main Chota Platform.

Goal 1 implementation is in progress in [issue #1](https://github.com/chotabyorg/conversation-service/issues/1), linked to [Project #3 Foundation](https://github.com/orgs/chotabyorg/projects/3/views/1?pane=issue&itemId=263003543). The [Main Conversation ADR](https://github.com/chotabyorg/gitops/blob/main/docs/main-chota-conversation-foundation.md) defines the boundary.

This repository is separate from the paused fashion/e-commerce Chota 2.0 product (`chotabyorg/chota`, Project #6).

**Not deployed. No production channel uses this service.** Existing gateways and the legacy AI path remain in use. This repository has no automatic deployment workflow or GitOps runtime resources.
