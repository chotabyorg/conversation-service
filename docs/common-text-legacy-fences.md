# Common text legacy fences

Legacy Telegram and Website authority transitions, Turn selection and delivery
creation lock retained/configured common grant scopes before the canonical root.
They recheck durable enrollment after the root lock, including when stale settings
miss a newly created scope. Grant generation or either revocation floor keeps an
integration enrolled after configuration removal or revocation.

Website's old UUID-only admission and response-begin path observes the same fence.
The immediate and settling selectors cannot create a new legacy Turn after common
enrollment. Undispatched legacy selections cannot become new dispatches; retained
already-dispatched recovery remains available for the existing operation ledger.
An exact retained admission, selection or delivery decision still replays before
new-work eligibility is evaluated. An originally authorized HTTP response keeps
its exact completion port; a replay never obtains a second send permission.

A UUID-only legacy caller cannot attach to or read a root created by the private
session-capability API. Common revocation includes roots from Website admissions
and session capabilities, even when an AGENT root has never had a Handoff case.
It advances the existing authority epoch, resume floor and outbound fences.

This is a private prerequisite. Website common provision/revoke stays disabled.
The Website v3 coordinator, credential-bearing admission/history, ordered idle
delivery and trusted permanent writer proof source remain required. Legacy
Website attempts have no process-incarnation proof: a finished UNKNOWN record,
browser disconnect or lease expiry cannot establish permanent writer termination.
Do not use these fences as permission to enroll a Website integration.

Validation uses real disposable PostgreSQL with fake suppliers and model ports:
durable generation/floor fences, exact replays, credential-root isolation,
scope/root contention, immediate/settling selection and revocation of roots
without a case. Existing Telegram Handoff, Turn and delivery suites remain
part of the regression selection. No paid traffic or production activation.
